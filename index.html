用 Grasshopper 學
生成式演算法的建築圖鑑

這裡把建築參數化設計常用的生成式演算法分成六大家族，每個演算法都附一支 Grasshopper C# 基礎範例，外加改法（變形）、真實應用案例與延伸專案題目，讓學習者從「看懂」一路走到「改成自己的東西」。

01怎麼使用

先用眼睛逛，再點進去看細節。圖鑑頁以圖片為主，文字都收在點開之後。

1

逛圖

瀑布流裡混著演算法、變形、案例與專案。看到喜歡的形，就是起點。

2

看懂怎麼運作

每個演算法用圖示拆解步驟，並可拉滑桿即時看參數怎麼改變形。

3

改成自己的

從變形食譜挑一個改法，或參考案例與專案種子，組合出自己的演算法應用。

02六大家族

家族看的是「長出來像什麼」；同一個家族裡會混用不同的演算法邏輯。演算法編號＝家族字母＋兩位數（例：A01）。

03五種演算法邏輯

看到一個演算法，先問兩件事：在變的東西是什麼（決定資料結構）、它靠哪種邏輯算出來（決定程式骨架）。

邏輯怎麼算什麼時候停例子
直接公式給座標或編號，直接算出結果，不需要上一步沒有迭代Phyllotaxis、Noise、TPMS、Truchet
改寫／遞迴規則把東西展開成更細的東西展開到第幾代，或太小就停L-System、Koch、Hilbert、Shape Grammar
迭代模擬每一步依上一步的狀態更新收斂到平衡，或開放地一直長Circle Packing、Differential Growth、Boids
搜尋／求解在很多可能的解裡，找合法或最好的那個找到解，或達到評分門檻WFC、基因演算法、Dijkstra、Poisson Disk
幾何轉換對輸入掃一遍，轉成另一種幾何掃完就停Voronoi、Marching Squares

04標籤怎麼看

形狀代表「哪一類」；只有身分鏈（家族 › 演算法 › 變形）使用家族色。

05課程背景

這個圖鑑最初為國立陽明交通大學的「演算法設計」課程整理，現在以通用形式公開，任何想用 Grasshopper 學習生成式設計的人都可以使用。

學校
國立陽明交通大學
課程
演算法設計
學期
115 學年度第 1 學期（115-1）
對象
具 Python 或 JavaScript 基礎的建築、設計背景研究生
工具
Rhino 8、Grasshopper、C# Script 元件、RhinoCommon

寫得出來

在 Grasshopper 裡用 C# 寫元件：型別、值型別與參考型別、資料流與 DataTree。

認得出來

認識六大家族的生成式演算法，能從一張圖判斷它的家族、邏輯與資料結構。

拆得開來

先用 pseudocode 拆解狀態、規則與迴圈，再實作成 C#，理解演算法的思考方式。

長成自己的

挑選一到兩個演算法深入研究、自己做變化，完成一件建築或設計的演算法應用專案。
